Kebijakan Privasi

Terakhir diperbarui: 7 November 2026

Ringkasnya: Board Game Maroe adalah proyek hobi gratis tanpa iklan dan tanpa analitik. Kamu bisa bermain tanpa akun. Data hanya disimpan kalau kamu masuk dengan Google, dan itu pun sebatas yang dijelaskan di bawah. Data tidak dijual atau dibagikan untuk keperluan lain.

1. Data yang tersimpan di perangkatmu

Game menyimpan nama panggilan, avatar, statistik, hasil tantangan harian, dan pengaturan (misalnya tampilan dan suara) di penyimpanan lokal browser (localStorage). Data ini tetap di perangkatmu dan hilang kalau kamu menghapus data situs di browser.

2. Kalau kamu masuk dengan Google (opsional)

Masuk dengan Google bersifat opsional dan dipakai supaya statistikmu ikut ke HP lain. Login ditangani oleh Firebase Authentication milik Google.

  • Yang diterima Firebase dari akun Google-mu: alamat email, nama, dan foto profil. Password Google-mu tidak pernah kami terima.
  • Yang disimpan game di database (Firestore): nama panggilan, avatar, tanggal mulai bermain, statistik per game, dan waktu pembaruan terakhir.
  • Email-mu tidak ditampilkan kepada pemain lain dan tidak ditulis ke database game.

3. Papan peringkat (publik)

Kalau kamu masuk dengan Google dan mencetak skor, nama panggilan, avatar, dan skor terbaikmu bisa dilihat semua pemain di papan peringkat. Jangan pakai nama asli atau informasi pribadi sebagai nama panggilan kalau kamu tidak mau itu terlihat.

4. Bermain online

  • Untuk bermain online, game membuat akun anonim otomatis berisi ID acak. Tidak ada data pribadi di dalamnya.
  • Langkah permainan dikirim lewat database (Firestore) sebagai pesan singkat dengan kode ruangan. Pesan itu hanya berisi data langkah dan diberi waktu kedaluwarsa 6 jam.
  • Jangan membagikan kode ruanganmu ke orang yang tidak kamu kenal.

5. Layanan pihak ketiga

  • Firebase (Google): login, database, dan pemuatan skrip Firebase. Google menerapkan kebijakan privasinya sendiri.
  • Google Fonts: untuk memuat huruf. Seperti situs web pada umumnya, ini membuat alamat IP-mu terlihat oleh Google.
  • GitHub Pages: tempat situs ini di-hosting. GitHub bisa mencatat log akses standar.

Situs ini tidak memakai iklan, pelacak iklan, maupun layanan analitik.

6. Menghapus data

  • Data lokal: hapus data situs ini lewat pengaturan browser.
  • Data akun: kalau kamu ingin akun dan datamu (nama panggilan, avatar, statistik, skor papan peringkat) dihapus dari server, hubungi maruhawa.stevanus@gmail.com dan sebutkan nama panggilanmu.

7. Anak-anak

Game ini untuk umum, tetapi kami tidak sengaja mengumpulkan data pribadi dari anak-anak. Anak-anak sebaiknya bermain tanpa masuk akun, atau dengan izin orang tua.

8. Perubahan kebijakan

Kebijakan ini bisa berubah kalau fitur game berubah. Tanggal pembaruan terakhir tercantum di bagian atas halaman.

9. Kontak

Pertanyaan soal privasi: maruhawa.stevanus@gmail.com
